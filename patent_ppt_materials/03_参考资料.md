# 相关工作与检索提醒

以下仅作为 PPT 相关工作和正式查新的起点。

| 方向 | 代表工作 | 与本项目的关系/提醒 |
|---|---|---|
| Prompt-based KG augmentation | [Prompting Large Language Models with Knowledge Graphs for Question Answering Involving Long-tail Facts](https://arxiv.org/abs/2405.06524) | 证明 KG triples 可改善长尾问答，但仍主要通过上下文提示承载知识 |
| Reasoning + acting | [ReAct: Synergizing Reasoning and Acting in Language Models](https://arxiv.org/abs/2210.03629) | 代表多轮 Thought/Action/Observation 工具路线 |
| Iterative graph tools | [Think-on-Graph](https://arxiv.org/abs/2307.07697) | 代表 LLM 在 KG 上迭代搜索推理；需与一次性可执行程序区分 |
| Graph retrieval efficiency | [Fast Think-on-Graph](https://arxiv.org/abs/2501.14300) | 指出现有强耦合图方法在稠密图上可能计算和时间开销较高 |
| Executable code for KGQA | [KG2Code](https://arxiv.org/abs/2607.22652) | 与“代码式、可验证 KGQA”接近，是宽泛程序生成权利要求的重要风险项 |
| Graph-path supervision | [Knowledge-Graph Paths as Intermediate Supervision for Self-Evolving Search Agents](https://arxiv.org/abs/2605.05702) | 已公开图路径用于出题接地和过程奖励；本项目需突出类型化执行认证与接口门控 |
| KG/self-play co-evolution | [CoEvoKG](https://arxiv.org/abs/2608.01904) | 已公开生成器—求解器—知识图闭环；本项目不应宽泛声称“首次图自演化” |
| Self-play + persistent memory | [Self-Play Meets Skill Evolution](https://arxiv.org/abs/2607.29468) | 已公开分离参数的出题者/求解者与持久记忆演化，需突出具体更新和认证机制 |

## 建议正式查新关键词

中文：知识图谱问答、可执行图程序、程序合成、任务生成、执行认证、自博弈、课程奖励、条件奖励、任务归档、双适配器、同轮更新。

英文：knowledge graph question answering, executable graph program, program synthesis, certified task generation, execution-derived gold answer, curriculum self-play, interface readiness, conditional semantic reward, deterministic task admission, separate adapters, same-round training.
