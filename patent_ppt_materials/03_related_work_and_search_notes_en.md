# Related Work and Prior-Art Search Starting Points

These references support presentation background and later professional searching. They do not establish novelty or patentability.

| Direction | Representative work | Relevance and caution |
|---|---|---|
| Prompt-based KG augmentation | [Prompting Large Language Models with Knowledge Graphs for Question Answering Involving Long-tail Facts](https://arxiv.org/abs/2405.06524) | Graph triples support long-tail QA, while knowledge remains primarily in prompt context |
| Reasoning and acting | [ReAct: Synergizing Reasoning and Acting in Language Models](https://arxiv.org/abs/2210.03629) | Representative Thought/Action/Observation tool paradigm |
| Iterative graph tools | [Think-on-Graph](https://arxiv.org/abs/2307.07697) | Representative iterative KG search; compare with one-shot executable programs |
| Graph-retrieval efficiency | [Fast Think-on-Graph](https://arxiv.org/abs/2501.14300) | Discusses computation and latency in strongly coupled graph reasoning |
| Executable code for KGQA | [KG2Code](https://arxiv.org/abs/2607.22652) | Close to code-based verifiable KGQA; important for broad claim risk |
| Graph-path supervision | [Knowledge-Graph Paths as Intermediate Supervision for Self-Evolving Search Agents](https://arxiv.org/abs/2605.05702) | Uses paths for grounded generation and process reward; distinguish typed certification and interface gating |
| KG/self-play co-evolution | [CoEvoKG](https://arxiv.org/abs/2608.01904) | Generator–solver–KG co-evolution; avoid a broad “first graph self-evolution” position |
| Self-play with persistent memory | [Self-Play Meets Skill Evolution](https://arxiv.org/abs/2607.29468) | Separated proposer/solver roles and persistent evolution; emphasize the certified order and archive policy |
