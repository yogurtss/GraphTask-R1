# GPT Image Prompt Set — Enriched Patent-PPT Figures

## Shared edit specification

Each `v3` image was produced by editing its corresponding `v2` image with the built-in GPT Image workflow.

Preserved across all figures:

- 16:9 composition and navy title band
- warm-white background
- deep navy, slate gray, and muted antique-gold palette
- flat 2D engineering-diagram construction
- thin lines, rectangular modules, uppercase typography, and generous spacing
- existing technical flow, labels, and footer statement

Added across all figures:

- very light blue-gray module fills
- narrow internal header rules
- restrained monochrome line icons
- numbered process markers
- one secondary technical-information layer
- muted gold limited to the inventive core or critical provenance path

Explicitly excluded: bright colors, gradients, shadows, glow, 3D effects, cartoon imagery, decorative backgrounds, excessive icons, dense microtext, logos, and watermarks.
